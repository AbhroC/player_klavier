  1. Pausiere an einer Stelle, an der Balken beider Hände auf die Tasten treffen.
  2. Ziehe die waagerechte Linie knapp über die Tastatur, oberhalb der Funken.
  3. Ziehe die zwei senkrechten Linien auf die linke und rechte Kante der Tastatur.
  4. Die kleinen Striche müssen auf den Tasten sitzen: weiß auf weißen, rot auf schwarzen. Sonst den Tastenbereich ändern.
  5. Tippe auf Farbe wählen und dann auf einen Balken der jeweiligen Hand. Die Punkte auf der Linie zeigen, was erkannt wird.
